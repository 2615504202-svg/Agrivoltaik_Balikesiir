# Balıkesir Agrivoltaik Sistem Analizi
Bu proje Balıkesir bölgesi için güneş konumu, ışınım ve agrivoltaik sistem performans analizlerini içermektedir.
- **Veri Kaynağı:** PVGIS / TMY (`balikesir_tmy.csv`)
- **Lisans:** MIT License (Akademik kullanım)
- **Çalıştırma:** `pip install -r gereksinimler.txt` komutundan sonra `01_Balikesir_Agrivoltaik.ipynb` dosyasını çalıştırın.
